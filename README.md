# Hi, I'm Giacomo 👋

**Robotics, Control & Embedded Systems Engineer** based in Bologna, Italy.

I hold an MSc in Automation Engineering from the University of Bologna (110/110 cum laude). For my thesis I worked on distributed control of orbital robot swarms, which we tested in a microgravity campaign at the **ESA Orbital Robotics Lab** (ESTEC). I also built a **ROS2 autonomous drone** that uses vision to land precisely without GPS. These days I write embedded firmware in industrial R&D, working across C++, PLCs and system integration on real machines.

### 🔧 Currently
- **Embedded Firmware Engineer, R&D** at System Electronics (consultant via Overtech Consulting): firmware and control software for automatic battery formation machines in C++ and Python, plus machine logic on Beckhoff TwinCAT (IEC 61131-3 ST). I'm also the Software System Engineer, handling design and integration across firmware, PLC and PC software.

### 🛰️ Selected projects
- **Orbital Robot Swarms (MSc thesis, ESA Academy Experiments Programme):** distributed multi-robot control for Active Debris Removal and target encirclement. I built a mixed real/virtual simulation framework (ROS2, Gazebo, C++, Python) and validated it in microgravity at ESTEC.
- **Autonomous Drone (NOE APS, co-founder):** ROS2/MAVROS on Raspberry Pi with visual odometry, visual servoing and pose estimation for GPS-independent precision landing, time-optimal trajectory planning, and a web Ground Control Station.
- **UniBo Motorsport (Formula Student), Control Systems Division Manager:** led a 6-person team working on torque vectoring, traction control, regenerative braking and EKF-based vehicle state estimation in MATLAB/Simulink, with VCU integration.
